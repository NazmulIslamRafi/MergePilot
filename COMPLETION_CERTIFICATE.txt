USAGE QUICK START
════════════════════════════════════════════════════════════════════════════════

KEYBOARD SHORTCUT:   Ctrl+B (Open Repository Manager)

BASIC WORKFLOW:
  1. Press Ctrl+B
  2. Click "➕ Add Repository"
  3. Browse to local repository (must contain .git)
  4. Click "🔄 Refresh Branches"
  5. Close dialog
  6. Branches appear in Source/Target dropdowns
  7. Select and merge ✅

SETTINGS LOCATION:   %LOCALAPPDATA%\MergePilot\settings.json
